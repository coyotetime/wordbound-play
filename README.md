# Wordbound — playable build

A quiet two-player word game. This repository holds **only the built game**: one
self-contained HTML file, no source and no design documents.

Open the link, then **Share → Add to Home Screen** on iOS to get an icon that
launches full screen and keeps working offline — the whole game, dictionary
included, is in that one file.

Two people can play on separate phones with no server and no account: tap
**Play a friend** and send each other one short code per turn.
